# Data layer

Edit these files, then run `python3 tools/build.py`. The build rewrites the HTML pages in place.
Use `CCC_TODAY=2026-12-01 python3 tools/build.py` to preview a different date.

## chapters.json

`regions[]`: key, label, anchor (the #id on /chapters/), continent (key in continents.json).

`chapters[]`:

| field | meaning |
| --- | --- |
| slug | URL slug, matches /chapters/<slug>/ |
| name | display name |
| region | a regions[].key |
| country, city, state | location text |
| status | `active`, `forming` or `coming-soon` |
| lat, lon | map position |
| contact | chapter contact email |
| leaders[] | name, role, company, photo (path under assets/), linkedin, website |

Renders: chapter lists, leader grids, the chapter count everywhere (`<!--n:chapters-->`), the continent maps and pins, the region index on the home page.

## events.json

`events[]`: slug, title, start, end (ISO dates), chapter (slug or empty), online (true/false), format (`mixer`, `chapter-meeting`, `virtual-forum`, `job-fair`, `workshop`, `expo`, `other`), meta, tags.
An event disappears from upcoming lists the day after its `end`, both at build time and in the browser (`data-end`). Past event pages stay.
To add an upcoming event: add it here, create its page under /events/<slug>/, and add its row to the home list and events index (those two are pruned by the build, not generated).

## continents.json

Per continent: name, box [lon0, lon1, lat0, lat1], k, cx, width, height, path. Generated by `tools/make_continents.py`.

## site.json

`eventsPerYear`: editorial figure shown on the home page.
`heroes`: page key (home, about, events, membership, contact, resources, chapters) to a hero name in `assets/img/heroes/`.
`heroAlt`: alt text for the banner on each page key.

## Heroes

Images live in `assets/img/heroes/<name>.webp` (1600w) plus `-480w`, `-800w`, `-1200w`. Each chapter in `chapters.json` has a `hero` field (a hero name; US chapters share four regional heroes). The build sets og:image per page and inserts a `.page-hero` banner on about, events, membership, contact, chapters and each chapter page. All hero images are AI-generated scenes of invented people.

## Number markers

`<!--n:chapters-->26<!--/n-->` (also active, forming, regions, eventsyear) is replaced with the live number.
Region blocks use `<!--data:atlas-->`, `<!--data:forming-->` and `<!--data:regions-->`.
